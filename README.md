# Holon Vaadin Flow

Enterprise-grade UI components and utilities for building scalable Vaadin 25 applications with the Holon Platform.

## Features

- **HeroStrip Component**: Rich gradient card with metrics display, icon support, and responsive layout
- **Holon Integration**: Seamless DataStore, Property Set, and Security integration
- **Responsive Design**: Mobile-first layouts with intelligent breakpoints
- **Enterprise Ready**: Production-grade components with comprehensive testing

## Quick Start

See the demo at `/hero-strip` for component examples and usage patterns.
